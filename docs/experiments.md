## 实验一（B 方案：TF-IDF + LogisticRegression）

运行：

```bash
cd backend
python scripts/train_model.py
```

- 特征：jieba 分词 + TF-IDF，unigram + bigram，`class_weight="balanced"`。
- 划分：训练:测试 = 7:3，分层抽样；测试集 51 条（正 18 / 负 33）。

实际输出：

```
              precision    recall  f1-score   support
           0     1.0000    1.0000    1.0000        33
           1     1.0000    1.0000    1.0000        18
    accuracy                         1.0000        51
```

说明：

- 数据集模板高度相似（同一批话术套不同岗位名），随机划分后测试样本与训练样本近乎重复，
  **1.000 不是泛化性能**，只能说明模型能拟合本标注集。
- 训练产物：`backend/app/data/model.pkl`、`vectorizer.pkl`，已纳入仓库以便离线演示；
  重新训练会覆盖。
- 接入验证：正样本 P(招转培)=0.778，负样本 P=0.221；`/analyze` 返回
  `classify_available=true`。
